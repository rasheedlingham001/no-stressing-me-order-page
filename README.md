# No Stressing Me Custom DTF Order Page

Mobile-friendly customer order builder for custom DTF apparel.

## Customer webpage

After GitHub Pages is enabled, share:

**https://rasheedlingham001.github.io/no-stressing-me-order-page/**

## Enable GitHub Pages

1. Open **Settings** in this repository.
2. Select **Pages** under **Code and automation**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Open the **Actions** tab and run **Deploy GitHub Pages** if it does not start automatically.

## Included features

- Multiple prints on one product
- Standard and custom print sizes through 13 × 15 inches
- Print-location selection
- Black, White, and Gray standard colors
- Special-order color requests
- V-neck, T-shirt, hoodie, and hat products
- Jersey names and large numbers
- Left/right shoulder personalization in 3 × 3, 3 × 4, 4 × 3, 4 × 4, 4 × 5, and 5 × 5 sizes
- Per-item pricing and line totals
- Artwork selection and email-ready order summaries

Artwork files remain on the customer's device and must be attached when the prefilled email opens.
